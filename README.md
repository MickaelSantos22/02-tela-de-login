# 🔐 Tela de Login

Projeto de desenvolvimento de uma interface de login, criado como parte dos meus estudos em Front-End.

## 📌 Sobre o projeto

O objetivo deste projeto foi praticar a construção de interfaces web, trabalhando a estruturação de páginas com HTML e a estilização com CSS.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 🎯 Aprendizados

Durante o desenvolvimento, pratiquei conceitos de:

- Estruturação de páginas HTML.
- Estilização de elementos com CSS.
- Organização de componentes visuais.
- Construção de interfaces para aplicações web.
